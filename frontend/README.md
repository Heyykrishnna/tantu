# tantu frontend

The Next.js/React L1A application: secure sign-in, workspace switching, task/page lists and detail editing, invitations, files, activity and internal job controls. Data comes from the real Fastify service; there is no seeded production dashboard.

## Run

Use Node.js 24/npm 11 and the [local setup guide](../docs/l1a/setup.md). Start the database, backend and worker before using the application:

```bash
npm run dev
```

Open [localhost:3000](http://localhost:3000). `/api/v1` is rewritten to `BACKEND_ORIGIN`, defaulting to loopback port 4000. [.env.example](.env.example) contains the public-service routing setting; credentials remain on the backend. Build-time routing must match the actual deployment and the backend's exact `APP_ORIGIN`.

## Behavior and validation

Task/page IDs survive routes and reloads. Saves use operation keys and expected versions; conflicts retain the draft. Session storage holds user/workspace/record-scoped drafts and retry identity on the current device until saved or explicitly cleared by logout. Light/dark tokens, native controls, visible focus, responsive layout and a keyboard command dialog provide the local UI baseline.

Page editing supports bounded paragraphs and headings. Script/HTML text is never rendered as active HTML. Read-only grants disable edits. Files remain quarantined until the actual scanner approves them; no active attachment preview is implemented.

Run `npm run lint`, `npm run typecheck` and `npm run build`. From the root, `npm run check:l1a` also tests the built interface through actual HTTP and PostgreSQL. System fonts require no external font fetch. Canonical types are generated by the backend's `contracts:types` command and verified by `contracts:check`; browser responses are validated before use.

Follow [AGENTS.md](AGENTS.md) and the installed Next.js documentation before framework changes. Automated checks do not replace manual screen-reader and participant testing. See [readiness](../docs/l1a/readiness.md) for deployment and security boundaries.
